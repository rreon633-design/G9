# Using G9

G9 is a player, not a TV service. You bring files or a playlist you are allowed to use.

## First run

- Drag-and-drop is not required: use **Open file**.
- Or **Add playlist** and paste an M3U / enter its URL.
- Or Settings → **Load demo clips** (Big Buck Bunny and friends — not live TV).

## Live TV

After import, open **Live TV**. Click a row or type a channel number. `↑` / `↓` zaps. Star a channel to favourite it.

## Keys

| Key | Action |
|---|---|
| Space | Play / pause |
| ↑ ↓ | Previous / next channel |
| 0–9 | Number-pad tune |
| F | Fullscreen |
| D | Diagnostics |
| / | Search |

## Privacy

Everything stays on your machine (`g9.db` in the OS app-data directory). No account, no telemetry.
